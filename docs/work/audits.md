# Flow audits

What each batch measured, written by the agent after a release (`/flow-audit`). The hard
points an audit finds are `FLOW-NNN` entries in `flow/`. The last two batches are kept:
each figure stands beside the one before.

---

The private build waited about an hour on GitHub's timer after the release (FLOW-047).
